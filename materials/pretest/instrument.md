## SoSci system fields

The 53 entries above are the questionnaire's own variables. The raw export carries
24 further columns that SoSci Survey writes for every interview. The descriptions
below are the labels SoSci itself records in
`data/raw/Pretest/variables_digital-altruism-pretest_2026-06-12_11-16.csv`, so this
table restates the export rather than interpreting it.

None of the 24 enters an analysis. `02_study2/01_process_pretest.R` reads the
questionnaire variables only.

| Column | Meaning |
|---|---|
| `CASE` | Interview number (sequential) |
| `SERIAL` | Serial number (if provided) |
| `REF` | Reference (if provided in link) |
| `QUESTNNR` | Questionnaire that has been used in the interview |
| `MODE` | Interview mode |
| `STARTED` | Time the interview has started (Europe/Berlin) |
| `TIME001` | Time spent on page 1 |
| `TIME002` | Time spent on page 2 |
| `TIME004` | Time spent on page 4 |
| `TIME005` | Time spent on page 5 |
| `TIME006` | Time spent on page 6 |
| `TIME007` | Time spent on page 7 |
| `TIME008` | Time spent on page 8 |
| `TIME_SUM` | Time spent overall (except outliers) |
| `MAILSENT` | Time when the invitation mailing was sent (personally identifiable recipients, only) |
| `LASTDATA` | Time when the data was most recently updated |
| `STATUS` | Interview status marker |
| `FINISHED` | Has the interview been finished (reached last page)? |
| `Q_VIEWER` | Did the respondent only view the questionnaire, omitting mandatory questions? |
| `LASTPAGE` | Last page that the participant has handled in the questionnaire |
| `MAXPAGE` | Hindmost page handled by the participant |
| `MISSING` | Missing answers in percent |
| `MISSREL` | Missing answers (weighted by relevance) |
| `TIME_RSI` | Completion Speed (relative) |

Times are in seconds, one column per questionnaire page. The export carries no
`TIME003`, so the page numbering skips it. `MAILSENT` is empty throughout, because
the pretest used an open link rather than personalized invitations.
