# Python dependencies of the feature-generation scripts, pinned to the versions that
# actually produced the shipped feature tables. This file is the counterpart to
# renv.lock on the R side, and the pins are the point of it.
#
# The versions matter more than they look. spaCy 3.8.16 finds slightly different
# named entities than 3.8.13, which changes rows in entities_*.csv. A range like
# >= would let a fresh install drift and the feature tables would stop matching.
#
#     python3 -m venv .venv && source .venv/bin/activate
#     pip install -r python/requirements.txt
#
# Recorded from the environment the features were generated in, Python 3.14.4.
