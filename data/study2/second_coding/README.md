# Study 2 — second coding of the advertisement comments

All 71 advertisement comments received three independent readings. This folder holds the
second and third of them, and the comparison the thesis reports.

## Files

| File | What it is |
|---|---|
| `second_coder_codes.csv` | The independent second coder's stance codes. Collected through a purpose-built browser interface that showed **only the comment text**: no condition, no advertisement name, and none of the first coder's codes. |
| `llm_coder_codes.csv` | The third reading, a language model blind to both. |
| `coding_comparison_3way.csv` | All three readings side by side. |
| `consensus_codes.csv` | The resolved codes used for the reported frequencies. |
| `intercoder_reliability.csv` | Per-category agreement between coder 1 and coder 2, briefed pass. |
| `intercoder_reliability_PASS1_unbriefed.csv` | The same before the second coder was briefed on the codebook. |
| `second_coder.html` | The blind coding interface itself. Open it in a browser to see what the second coder saw: the comment text and nothing else. |
| `BLIND_texts_for_llm_pass.json` | The 71 comment texts as handed to the language model, index and text only. |

Reproduce with `python3 ../../../python/compute_intercoder_kappa.py`. The interface is generated by
`../../../python/build_second_coder.py`.

## Two naming traps, both real, both checked

**1. `author_retest` is the second coder, not the author.** The column carries a legacy name
from an earlier plan in which the author would re-code. It is byte-identical to
`second_coder_codes.csv`, 71 of 71, Cohen's κ = 1.000. Three separate review reports read the
column name and concluded the thesis had used a single coder. It had not.

**2. Coder 1 exists in two versions, and only one of them belongs in a reliability figure.**

| Comparison | Agreement | κ |
|---|---|---|
| `author_original` vs second coder | **66.2% (47/71)** | **.515** |
| `MetaAds_comments_coding.csv` vs second coder | 80.3% (57/71) | .720 |

The second file holds coder 1 **after** consensus resolution, so the resolution has already
absorbed the second coder's reading and the agreement is inflated. **The thesis reports the
pre-resolution figure**, which is the first row and the only defensible one. An earlier version
of the reliability script read the resolved file and returned 80.3%; that is fixed.
